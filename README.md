# dot

משימה 2, המרחב הלטנטי. קורס של דפני.

- `index.html`: עשרים שיטות לפיזור עיגולים, בשפה של tz.
- `memory.html`: זיכרון סינתטי. אותו רגע היסטורי בהרבה גרסאות של מודל גנרטיבי. איפה שהגרסאות מסכימות הנקודות שומרות על סדר של מסמך, ואיפה שהן נפרדות או רחוקות מהמקור, הסדר נשבר.

קבצי HTML עצמאיים, בלי build. פריסה ב GitHub Pages מהענף main, מהתיקייה הראשית.
